# git

Git の操作に関わる共有ルール。[AGENTS.md](AGENTS.md) を常設ルールとして配り、コミットの主題、squash と rebase の選択、worktree の作り方と統合、PR の扱いを定める。

これらはコミットや統合のたびに要り、どのセッションでも起きるので、スキルの呼び出しを待たずに読み込む。スキルとして配っていたころは、git の操作をしたセッションのうち読まれたのは 2 割前後で、読まれなかったセッションのコミットには AI の関与を示す行が残っていた。常設ルールはサブエージェントにも届く。

統合担当は取り込み後の組み合わせを検証し、変更の保存先を確認してから worktree を削除する。具体的な検査コマンド、ブランチ名、CI の発火条件は対象プロジェクトが持つ。誰が worktree を用意し、誰がそこで作業するかの分担は `collaboration` モジュールが持つ。

`git` が PATH にあるかを確認する。インストールは行わない。
