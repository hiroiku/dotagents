# collaboration

ユーザーとの対話を担当するセッションと、実作業を担当するサブエージェントを分けるモジュール。[AGENTS.md](AGENTS.md) を常設ルールとして配布する。

対話を担当するセッションは、サブエージェントや CI をバックグラウンドで待ち、そのあいだターンを終えてユーザーと会話できる状態に戻る。完了は通知で届くので、待つためのコマンドは要らない。常設ルールはサブエージェントにも届くので、待ち方の規則には主語として「対話を担当するセッション」を書き、サブエージェントが自分の待ちでターンを終えないようにしている。

サブエージェントが最も強く従うのは、最初に受け取る依頼文である。依頼文では検証を「作業中の確認」と「仕上げの検査」に分けて書き、重い検査が作業中に繰り返されないようにする。

この作業分担を使うプロジェクトに `dotagents install collaboration` で追加する。このモジュールが持つのは、誰が何を担当するかだけである。worktree の作り方と統合の手順は `git` モジュール、完了時の独立レビューは `review` モジュール、検証の範囲の選び方は `testing` モジュールが持つ。
