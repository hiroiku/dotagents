# issue を棚卸しする

開いている issue は、終える数より増える数が上回ると、どれが生きているかが読めなくなる。1 件ずつ決めて、1 回の確認で反映する。

1. 開いている issue を、古い順に並べる。
2. 1 件ごとに、やる(次のバッチに入れる)、やらない(理由を付けて閉じる)、戻す(順番を決めずに置く)のどれかを付ける。重複と、すでに直っているものは、やらないに入れる。重複は、残すほうを参照して閉じる。
3. やるものは、書かれた直し方が共通ルールの設計の基準に沿っているかを確かめ直す。古い issue は、いまの基準に沿っていないことがある。
4. 1 つの表にして利用者に出し、1 回の確認で反映する。閉じる理由は、実際に起きたことに合うものを選ぶ。
